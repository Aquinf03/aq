Jobs

aq jobs is remote background work on an SSH place (or pool). Spec, pid, logs, and exit code live under <remoteDir>/jobs/<id>/. Full path: SSH fleet.

Verbs

CommandWhat it does
aq jobs run --on p -- <cmd>Start a background command
aq jobs train|eval|serveSame as run -- aq train|eval|serve
aq jobs sweepFan-out shards / grid search
aq jobs list / status / logsInspect
aq jobs pull / downFetch artifacts or cancel
aq jobs recoverRestart after host/process death
aq jobs watch / manageAuto-recover loop + policy
aq jobs submitAlias → aq queue push
shell 
$aq jobs train --on temp
$aq jobs status <id> --json
$aq jobs logs <id> -n 80
$aq jobs recover <id> --next

Not the old job planner

The former aq job / aq schedule / YAML plans surface is gone. Local train stays aq train; background agents stay aq spawn agent. Remote compute is aq jobs on places.
