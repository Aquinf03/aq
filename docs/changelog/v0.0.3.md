# v0.0.3 — aquin.app/aq + install cutover

**2026-10-10**

Account, install, and release URLs live on **aquin.app**. Agent chat is **axi** (separate package). Framework stays **aq**.

## New

- **Account portal** at [aquin.app/aq](https://aquin.app/aq) (sign-in, desktop/CLI handoff, install strip).
- **Public install:** `curl -fsSL https://aquin.app/aq/download/install.sh | bash`
- **Releases** served via Cloudflare R2; `aquin.app/releases/…` (rewrite) and `aq update` use the same pipeline.

## Changes

- **`aq login`** opens `aquin.app/aq/?view=desktop&client=cli` (override host with `AQUIN_AUTH_URL`).
- Removed in-repo **`web/`** auth app — cut over to the Aquin site.
- **Agent** moved out of this repo to **axi** (`~/.axi`); `aq` no longer owns agent chat UI.
- Docs / changelog Sign in + install lines point at aquin.app.

## Install

```bash
curl -fsSL https://aquin.app/aq/download/install.sh | bash
aq version
aq login
```
