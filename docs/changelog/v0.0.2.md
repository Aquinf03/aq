# v0.0.2 — SDK + YAML + artifacts

**2026-09-24**

A run is **`recipe.yaml` (path map) + `artifacts/` (runtime)**. Author with **YAML and/or `aquin`** — both first-class. Same kernel for CLI.

Drive it with **`aquin`** or **`aq`** — same kernel.

## New

- **Python SDK (`aquin`)** under `aq/aquin`: few-line client over the kernel.
  ```python
  # YAML-first
  from aquin import Aquin
  aq = Aquin(".")
  aq.train(); aq.eval()

  # or SDK-first (writes the same recipe.yaml)
  aq = Aquin.define(
      family="tabular", method="linear",
      data={"path": "data.csv", "target": "y"},
      eval={"metric": "mse"},
      config_path="recipe.yaml",
  )
  ```
  Also: `Run` class, `.checkpoint()`, `.serve()`, `.hash()`, `.status()`, `Aquin.from_dict(...)`.
- **`aq init` / `python -m aquin init`:** scaffolds only:
  - `recipe.yaml` — path map (edit by hand and/or via SDK)
  - `example.py` — opens YAML by default; `define` path commented
  - `artifacts/` — runtime output template
- **Run identity:** `recipe.yaml` alone is enough (`assertTrain` / `openRun`).
- **`scripts/tests/sdk-ridge`:** YAML-first with `Aquin(".")`.
- **`scripts/tests/sdk-from-dict` / `scripts/tests/sdk-run-class`:** SDK-first (writes path map).
- Design notes: [`aq/SDK.md`](../../aq/SDK.md), [`docs/documentation/`](../documentation/).

## Changes

- Removed CLI verbs **`aq tool`**, **`aq stage`**, **`aq fork`**, **`aq job`**, **`aq schedule`**, and **`aq checkout`**. Renamed **`aq spawn run`** → **`aq spawn agent`**. Background workers still use an internal queue under `jobs/` (via spawn / agent detach).
- Removed job plans (`plans:` / `.plan` / `@schedule` / `@pipeline`).
- Removed init scaffolding for `experiment.md`, `data/`, `evals/`, `skills/`, `tools/`, `jobs/`, `stages/`. Put file paths in `recipe.yaml` instead.
- Default init folder name: `aq-run` (was `aq-experiment`).
- Default template recipe is tabular/linear (swap in YAML for LLM/etc.).
- Tests index updated for SDK-first; catalog lists vision/VLM suites.
- **YAML + SDK:** both optional authoring surfaces for the same path map.

## Fixes

- **guard.safety** no longer aborts the whole train on a single spike. It emits `guard.warn` and only stops after consecutive bad steps (`blowup_patience` default 3, `nan_patience` default 2). Warmup default raised to 20.

## Install SDK (checkout)

```bash
aq/kernel/.venv/bin/pip install -e ./aq
python -m aquin init my-run
```
