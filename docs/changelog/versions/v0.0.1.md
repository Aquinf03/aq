# v0.0.1 — First cut (pre-SDK)

**2026-08-31 → 2026-09-06**

Everything shipped before the SDK / path-map reboot. Collapsed from the old `0.0.1`–`0.0.4` line into one era.

## Concept

`aq` is the developer environment for foundation models: frameworks, libraries, tools, and autonomous agents that help you design, test, and refine models. Trains live on disk — a folder with your recipe and results. The CLI runs them: train, eval, serve, and chat with an agent in that folder.

## Install

```bash
curl -fsSL https://aq.aquin.app/framework/install.sh | bash
```

Needs Node 18+, Python 3, and npm. After install: `aq help` and `aq doctor`. Re-run install (or `aq update`) to replace an older copy. Windows (Git Bash + `aq.cmd`) supported.

## What landed in this era

### Train & evaluate

- `aq train` / `aq eval` / `aq serve` from `recipe.yaml`
- Tabular: linear/logistic, ridge, lasso, elastic net, trees, forests, boosting, GPs; CatBoost / LightGBM
- LLM: pretrain, SFT, full FT, LoRA, QLoRA, MLM, span corruption, FIM, continued training
- Vision CNNs + ViT / Swin / DeiT / BEiT; VLM (CLIP / SigLIP, LLaVA-style, Flamingo)
- Machine-aware compute: VRAM probe, auto bf16/fp16, batch / checkpointing, OOM retry
- Train + eval TUIs; weight export (`formats:` → HF / GGUF / etc.)
- `aq plot` for loss / jobs / runs

### Agent & tooling

- Interactive chat (`aq`), one-shot (`aq ask`), chat history under `~/.aq/chats/`
- `aq spawn` (background agent); optional critic via `--kill`
- Providers: OpenAI, Anthropic, Grok, Ollama
- `aq version`, `aq doctor`, `aq status`, `aq diff`

### Layout (superseded by 0.0.2)

Init used a fuller folder layout (`experiment.md`, `data/`, `evals/`, `skills/`, `tools/`, `jobs/`, `stages/`) and verbs like `aq job`, `aq schedule`, `aq stage`, `aq fork`, `aq checkout`. Those are gone in **0.0.2** — runs are now `recipe.yaml` + `artifacts/` with optional `aquin` SDK.
