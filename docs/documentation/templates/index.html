Templates

Copy-pasteable recipe and pipeline templates. Legacy ML “recipes” meant ingest→train→eval→register with step cache — in aq that is a train folder: paths in recipe.yaml, verbs for steps, artifacts/ as the cache. Start from a template, edit paths, run.

PrerequisiteTrain folder · aq init or copy a template into recipe.yaml · kernel deps installed

Pipeline shell · ingest → train → eval → register

Copy-paste flow. Artifacts under artifacts/ act as the step cache: re-run aq train only when recipe/data change; eval/register reuse the last checkpoint.

shell 
 # from a train folder with recipe.yaml + data
$aq train                 # fit → artifacts/checkpoints/
$aq eval                  # gate → metrics.jsonl + pass/fail
$aq status                # register view: run record + logged model id
 # optional SDK register stamp
$python -c "from aquin import log_model; log_model('artifacts/checkpoints/last.json')"

Legacy ‘recipe pipeline’ tools did ingest→train→eval→register with step cache. In aq the train folder is that pipeline: paths in recipe.yaml are ingest; verbs are steps; artifacts/ is the cache.

SDK · Aquin.define (writes recipe.yaml)

Same path map as YAML; then train/eval/register in a few lines.

python 
from aquin import Aquin
 
aq = Aquin.define(
    family="tabular",
    method="ridge",
    data={"path": "data.csv", "target": "y"},
    eval={"metric": "mse"},
    config_path="recipe.yaml",
)
aq.train()
print(aq.eval())
print(aq.status())  # run record + logged model
