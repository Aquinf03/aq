Agent

The aq agent lives inside the train Unix: same cwd, same files, same verbs. On a TTY, bare aq opens chat. It is not a chat toy with a private filesystem.

Prerequisiteaq provider configured · cwd is a train folder

aq / aq agent

Interactive agent chat (TTY). Uses tools that wrap aq verbs against this train.

example 
$aq

aq ask <prompt>

One-shot answer without the interactive UI.

FlagDescription
-y / --yes Auto-approve shell run.
--json Emit { text, tools }.
example 
$aq ask "hash the data then train"
example 
$aq ask -y "run eval and summarize"
example 
$aq ask --json "what failed last run?"

aq chat list | last | <id>

List or resume chats under artifacts/chats/.

example 
$aq chat list
example 
$aq chat last
example 
$aq chat <id>

aq spawn agent -- <prompt>

Background worker agent. list / log / cancel manage workers under artifacts/agents/.

example 
$aq spawn agent -- "train then eval"
example 
$aq spawn list
example 
$aq spawn log <id>
example 
$aq spawn cancel <id>
