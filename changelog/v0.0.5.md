# v0.0.5 — SDK + YAML + artifacts

**To be shipped**

Run identity is no longer a full train-directory OS. A run is **`recipe.yaml` + `artifacts/`** (created on train). `experiment.md` is optional. Drive it with the **`aquin` SDK** or the existing **`aq` CLI** — same kernel.

## New

- **Python SDK (`aquin`)** under `sdk/`: few-line client over the kernel.
  ```python
  from aquin import Aquin
  aq = Aquin("tests/sdk-ridge")  # or path to recipe.yaml
  aq.train()
  aq.eval()
  ```
  Also: `.checkpoint()`, `.serve()`, `.hash()`, `.status()`, `Aquin.from_dict(..., config_path=...)` (always writes durable YAML).
- **Run identity:** `recipe.yaml` alone is enough (`assertTrain` / `openRun`). No required slot forest for train/eval.
- **`tests/sdk-ridge`:** `example.py` + `recipe.yaml` — canonical few-line SDK sample (no `experiment.md`).
- **`tests/sdk-from-dict`:** `example.py` uses `Aquin.from_dict` (writes YAML, then trains).
- **Tests index:** suite READMEs note CLI + SDK; catalog and `tests/README.md` rewritten for the new shape.
- Design notes: `internals/author/sdk-first.md`, examples, and TODO checklist for the rest of the migration (plans-in-YAML, shrink `aq init`, torch parity docs, etc.).

## Changes

- CLI help / init messaging: rename freely; aq keys off `recipe.yaml`. `aq init` still scaffolds optional briefs and legacy slots for convenience — not required identity.
- Removed standalone `examples/` tree; SDK fixtures live under `tests/`.

## Fixes

- **guard.safety** no longer aborts the whole train on a single spike. It emits `guard.warn` and only stops after consecutive bad steps (`blowup_patience` default 3, `nan_patience` default 2). Warmup default raised to 20.

## Install SDK (checkout)

```bash
aq/kernel/.venv/bin/pip install -e ./sdk
# kernel deps: pip install -r aq/kernel/requirements.txt (same env)
```
